## 서브페이지 배너는 지금 비어 있습니다

`subheader_1~4.webp` 를 넣어 봤지만, 배경이 밝아 **흰색 제목이 묻히고** 제품 이미지가
가운데서 잘려 보여 전부 뺐습니다. 지금은 그라디언트만 나옵니다.
뺀 파일은 [자료넣기/image/보류_배너/](../../자료넣기/image/보류_배너/) 에 있습니다.

**나중에 배너 사진을 넣는 방법** — 두 단계면 됩니다.

1. 사진을 `public/images/` 에 넣습니다. (권장 3840×1310 · 최소 1920×655)
2. [lib/site.ts](../../lib/site.ts) 의 `SUBHEADER_BG` 에서 해당 항목의
   `image: ""` 를 `image: "/images/파일명.webp"` 로 바꿉니다.

```ts
export const SUBHEADER_BG = {
  sub01: { image: "/images/subheader_1.webp", fallback: "linear-gradient(...)" },
  //              ↑ 여기만 채우면 됩니다
```

| 키 | 쓰이는 메뉴 |
|---|---|
| `sub01` | TEST & DATA · ABOUT / CONTACT |
| `sub02` | (현재 메뉴에서 빠진 사업분야) |
| `sub03` | PRODUCT · HOW TO USE |
| `sub04` | DOWNLOAD |

**배너 사진 고를 때** — 제목이 **왼쪽에 흰색 80px** 로 얹힙니다.
왼쪽 절반이 어두운 사진이라야 읽힙니다. 밝은 사진밖에 없다면 왼쪽에 어두운
그라디언트를 덧대야 하고, 이건 [SubHeader.tsx](../../components/SubHeader.tsx) 수정이 필요합니다.
또 아래쪽 20% 는 반투명 검은 탭 바가 덮으므로 그 자리에 중요한 게 오면 안 됩니다.

## 히어로·배경에는 글자가 박힌 사진을 쓰지 마세요

`slide_*.webp` 와 `section_*bg.webp` 는 `background-size: cover` 로 깔립니다.
**화면 비율에 맞춰 좌우나 위아래가 잘리기 때문에**, 사진 안에 글자가 들어 있으면
어떤 화면에서는 글자가 반쯤 잘려 보입니다. 게다가 사이트 문구가 그 위에 또 얹혀
두 겹으로 겹칩니다.

처음에 카탈로그·제품소개서 페이지를 그대로 잘라 넣었더니 원본 디자인의
"색 변화로 바로 확인하는", "표면 공학의 극치" 같은 문구가 함께 딸려 와 잘렸습니다.
지금은 **글자가 없는 구간만 다시 잘라** 넣은 상태입니다.

| 파일 | 어디서 잘랐는지 |
|---|---|
| `slide_1.webp` | Micro-Anatomy 도해에서 제목 줄(위 15%)을 뺀 아래쪽 |
| `slide_2.webp` | 카탈로그 2p 에서 헤드라인·로고·흰 카드를 뺀 물 분사 구간 |
| `og.webp` | `slide_1` 과 같은 구간 |
| `slide_3.webp` | **예외** — 제품소개서 6쪽을 통째로 (아래 참고) |

`slide_3.webp` 은 제품소개서 6쪽에서 **아래 설명 카드 3개와 상단 로고를 잘라내고**
채널·볼 부분만 남긴 것입니다. 가로로 매우 긴 구도라 그냥 자르면 좌우가 잘려서,
사진의 배경 색을 위·아래로 그대로 이어 붙여 16:9 를 채웠습니다(이음매가 보이지 않습니다).

배너(`subheader_*`)도 같은 이유로 비워 둔 상태입니다. 위쪽 항목을 참고하세요.
**본문에 넣는 도해**(`tech_*.webp`)는 잘리지 않고 통째로 나오므로 글자가 있어도 괜찮습니다.

## 교체할 때 지켜야 할 크기

표시 크기의 **2배**가 기준입니다. 고해상도 화면(맥북·아이폰)이 CSS 1px 을 실제 점 2개로 그리기 때문입니다.
**작은 파일을 넣으면 늘어나면서 뭉개집니다. 큰 파일은 줄어들 뿐이라 안전합니다.**

| 자리 | 최소 | 권장 | 형식 | 주의 |
|---|---|---|---|---|
| `slide_*.webp` | 1920×1080 | **2560×1440** | WebP | 화면 전체라 세로로 크게 잘립니다. 피사체를 가운데에 |
| `section_3bg.webp` | 1920×1080 | **2560×1440** | WebP | `center right` 기준 — 오른쪽이 잘리면 안 됩니다 |
| `section_4bg.webp` | 600×800 | **900×1200** | WebP | 세로형(3:4). 가로 사진을 넣으면 양옆이 잘립니다 |
| `subheader_*.webp` | 1920×655 | **1920×655** | WebP | 왼쪽에 흰 글씨가 얹히므로 그쪽이 밝으면 안 읽힙니다 |
| `sub3*_img.webp` | 408×408 | **816×816** | **WebP (투명)** | 배경 투명 필수. 투명 없이 저장하면 검은 사각형이 생깁니다 |
| `tech_*.webp` | 1400 폭 | **2800 폭** | WebP | 안에 작은 글씨가 있어 크게 넣어야 읽힙니다 |
| `og.webp` | 1200×630 | **1200×630** | WebP | 이 비율 고정. 다르면 공유 카드에서 잘립니다 |
| `sub14_*.webp` | 400×550 | **800×1100** | WebP | 세로형 문서 |

**형식은 전부 WebP 입니다.** 같은 화질에서 JPG·PNG 보다 40~80% 가볍고 투명도도 지원합니다.
JPG·PNG 를 새로 넣어도 보이기는 하지만, 아래 명령으로 WebP 로 바꿔 통일하세요.

```bash
# 사진 (투명 없음)
python -c "from PIL import Image; Image.open('새파일.jpg').convert('RGB').save('새파일.webp','WEBP',quality=84,method=6)"
# 누끼 (투명 유지)
python -c "from PIL import Image; Image.open('새파일.png').convert('RGBA').save('새파일.webp','WEBP',quality=90,method=6)"
```

**용량** — 사진 200~350KB, 누끼 200KB 이하를 권합니다. 현재 폴더 전체는 약 4.9MB 입니다.

**캡쳐 화면을 넣을 때** — 원본(PPT·일러스트·PDF)에서 바로 내보내는 편이 훨씬 깨끗합니다.
캡쳐밖에 없다면 브라우저를 200% 로 확대한 뒤 찍어 픽셀을 2배로 확보하세요.
글자가 있는 이미지는 WebP 품질을 90 이상으로 올리면 글자 주변 얼룩이 줄어듭니다.

## 교체 전 반드시 확인할 것

지금 들어 있는 이미지 중 일부는 **자료정리 md 기준에 걸립니다.**
더 나은 원본이 생기면 우선 바꾸세요.

1. **`tech_micro_anatomy.webp` · `product_before_after.webp` 에 "Bullan Bio Solution" 로고가
   오른쪽 위에 박혀 있습니다.**
   제품소개서 7·8 쪽을 통째로 렌더한 것이라 원본 슬라이드의 로고가 따라왔습니다.
   md 5-1 은 회사명을 "놀란볼코리아 / Nolan Ball Korea" 로 통일하라고 정하므로,
   **원본 디자인 파일에서 로고를 교체해 다시 내보내는 것이 맞습니다.**
   (급하면 로고 자리만 배경색으로 덮을 수도 있지만, 원본 교체가 깨끗합니다.)

2. **도해는 "임베드된 이미지" 가 아니라 "페이지 렌더" 를 쓰세요.**
   PDF 안의 raster 만 뽑으면 그 위에 얹힌 **글자 레이어가 통째로 빠집니다.**
   실제로 처음엔 임베드 이미지를 썼다가 제목과 설명 라벨이 전부 사라지고,
   Micro-Anatomy 제목은 글리프까지 깨진 채로 들어갔습니다.

   ```bash
   # 7쪽을 200dpi 로 렌더 (글자 레이어까지 그대로 나옵니다)
   pdftoppm -png -r 200 -f 7 -l 7 "02.Nolan Ball_제품소개서.pdf" out
   ```

   | 도해 | 원본 |
   |---|---|
   | `tech_micro_anatomy.webp` | 제품소개서 **7쪽** 페이지 렌더 |
   | `product_before_after.webp` | 제품소개서 **8쪽** 페이지 렌더 |
   | `tech_structure.webp` | 병원제안서 임베드 이미지 (이건 글자가 이미지 안에 있어 괜찮습니다) |

3. **아래 두 이미지는 일부러 넣지 않았습니다.**

   | 파일 | 자리 | 넣지 않은 이유 |
   |---|---|---|
   | `06_시험결과_요약.png` | TEST & DATA | "0 CFU"·"완결됨" 표현이 md 4-3 **조건부**(시험 방법·단위·검출한계 병기 시에만 사용). 시험성적서 원문의 담당자 실명·서명도 포함 |
   | `03_핵심특징_요약.png` / `09_세척시간_도식.png` | 메인 | 이미지 안에 "구리 이온의 미세균 사멸/감소" 문구가 박혀 있음. md 4-3 **비권장** |

   두 파일 모두 [자료넣기/image/](../../자료넣기/image/) 에 있습니다.
   문구를 지운 버전이 준비되면 그때 넣으세요.

4. **`sub33_img.webp` 은 `sub32_img.webp` 과 같은 파일입니다.**
   기관지용 제품 사진이 따로 없어 위 내시경용과 같은 이미지를 씁니다.
   규격만 다르고 외형이 같다면 그대로 둬도 되고, 별도 사진이 생기면 교체하세요.

5. **저작권** — 병원제안서에는 방송 뉴스 캡쳐(조선·KING 5)가 들어 있습니다.
   그대로 웹에 올리면 저작권 문제가 생기므로 추출 후보에서 제외했습니다.
